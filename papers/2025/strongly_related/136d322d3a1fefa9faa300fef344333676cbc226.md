## abstract

Complex and sophisticated deep learning architectures often raise questions about trustworthiness and transparency, especially when we rely on these models for critical decision-making. If we can create arrangements where these complex models and explainability concerns work hand in hand, trust and confidence can be regained, enabling these technologies to be used more beneficially and in greater ways to serve humanity. In this paper, we work towards fulfilling this vision by developing a video-based human action recognition system using the I3D architecture on a dataset named Dataset Video For Human Action Recognition, which accurately classifies seven fundamental activities, while simultaneously providing interpretable explanations for each prediction. Our system utilizes the Inflated 3D ConvNet (I3D), pretrained on Kinetics-400, which combines spatio-temporal feature extraction with a streamlined classification head to recognize human actions, including Fall Down, Lying Down,etc. To address the black box nature of deep learning, we integrate multiple explainable AI techniques Grad-CAM for gradient-based attention visualization highlighting critical spatial regions, and SHAP for quantifying framelevel importance through masking analysis. The model achieves strong performance with top-1 accuracy of 77.86% on the test set, while top-2 and top-3 accuracies reach 91.54% and 96.02% respectively, demonstrating robust multi-class prediction capabilities. The confusion matrix reveals excellent performance on actions like Lying Down $(88.89 \%)$, Fall Down $(82.49 \%)$, and Walking $(82.81 \%)$. Our comprehensive XAI analysis provides actionable insights into model behavior, identifying key temporal moments and spatial attention patterns that drive predictions. This interpretable framework bridges the gap between highperforming deep learning model and human-understandable decision-making with particular relevance for safety critical applications.
